## 格式

- **png 或 jpg 都可以**，webp 也行
- 分鏡圖請用**豎屏 9:16**（角色設定圖不限，白底全身就好）
- 檔案大小不用壓，之後要上線再一起轉 WebP（站上圖片本來就是這樣處理的）

## 重生的版本怎麼命名

同一鏡重生時**加 `-v2`、`-v3`**，不要覆蓋掉舊的，方便對照哪一版比較好：

```
clip01-shot2.png      第一版
clip01-shot2-v2.png   重生的第二版
```
