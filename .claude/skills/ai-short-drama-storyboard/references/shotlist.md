# 分鏡表格式

## 欄位

每一鏡固定填以下欄位，缺的標「未定」，不留空：

| 欄位 | 說明 |
|---|---|
| 鏡號 | 場次-鏡次，例如 `1-03` |
| 景別 | 遠景／全景／中景／中近／特寫／大特寫 |
| 角度 | 平視／俯角／仰角／過肩／主觀 |
| 運鏡 | 固定／推／拉／橫搖／跟拍／手持 |
| 主體與動作 | 現在正在發生的可見行動，一鏡一件事 |
| 台詞 | 角色名＋台詞；無台詞寫「無」 |
| 秒數 | 估計秒數，台詞長度用實際唸過的時間估 |
| 聲音 | 環境音、音效、音樂進出點；靜默也要寫明 |
| 畫面文字 | 字幕、手機畫面、標題卡；無則寫「無」 |

## 豎屏欄位

指定豎屏（9:16）時，另外標示：

- **主體位置**：關鍵人物與動作落在畫面的上／中／下哪一段
- **安全區**：畫面文字是否避開平台介面會蓋到的上下緣

## 寫法規則

- 動作寫**看得見的東西**，不寫角色心裡想什麼：寫「她的手停在門把上」，不寫「她猶豫」。
- 景別要有理由：特寫用在資訊或情緒真的需要被放大時，不是每句台詞都推特寫。
- 運鏡預設「固定」；要動就要說得出這個動作在追什麼。
- 秒數要合計並對照指定時長，超過就回頭砍鏡，不要壓縮台詞。

## 短例

```text
場 1・內景・貓家客廳・夜

1-01 | 中景 | 平視 | 固定 | 2 秒
主體與動作：Tía Cemani 把伴手禮放上茶几，禮盒推到 Cata 面前三公分。
台詞：無
聲音：電視綜藝笑聲（低）
畫面文字：無

1-02 | 中近 | 平視 | 固定 | 4 秒
主體與動作：Cata 伸手要接，手停在半空。
台詞：Tía Cemani／「Tato 這麼木頭，我認識的人老公都會說 te quiero。」
聲音：電視笑聲在句尾切掉
畫面文字：無
主體位置：中段
```
