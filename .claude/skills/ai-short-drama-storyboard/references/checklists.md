# 分鏡與提示詞審閱清單

依影響程度排序回報：先講會讓觀眾看不懂或節奏垮掉的，再講風格偏好。每一項都要指到具體鏡號。

## 一、會讓人看不懂（最優先）

- [ ] 有鏡頭同時塞了兩件以上的資訊改變，觀眾抓不到重點
- [ ] 關鍵資訊只出現在畫面邊緣，豎屏被介面蓋掉
- [ ] 畫面文字太長，在指定秒數內讀不完
- [ ] 場景或角色外觀跨鏡不一致，看起來像換了人或換了地方
- [ ] 拿掉某一鏡之後，後面的鏡頭失去前提

## 二、節奏問題

- [ ] 秒數加總超過或遠低於指定時長
- [ ] 連續多鏡都是同一景別，情緒沒有推進
- [ ] 運鏡在沒有理由的地方一直動，分散注意力
- [ ] 台詞秒數是用字數換算的，沒有實際唸過
- [ ] 全片沒有任何靜默或停頓

## 三、越界（違反交付範圍）

- [ ] 在分鏡階段改了劇本的台詞、事件或角色
- [ ] 輸出了沒查證過的模型專屬參數
- [ ] 超出使用者指定的場景數、角色數或交付形式
- [ ] 放寬了使用者給的世界觀、用語或隱私限制

## 四、金句短片專用

- [ ] 這支片沒看過完整片就看不懂
- [ ] 前 1–2 秒沒有鉤子
- [ ] 結尾是硬切，沒有問題或情緒落點
- [ ] 為了短片另外增拍了完整片沒有的素材

## 回報形狀

每一項寫：**問題 → 證據（鏡號與該鏡內容）→ 造成的影響 → 可執行修正**。只有能說明修正理由，或使用者要求時，才直接給改寫版本。
